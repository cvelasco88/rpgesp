# Dorados

[Volver](./)

## Identidad

Los Tortugalos Dorados presentan pigmentación dorada, amarilla, ocre o ámbar. Sus caparazones y las marcas alrededor de los ojos pueden tener una intensidad dorada mayor.

## Rasgo cultural

Elige un archivo familiar, un pacto antiguo o un recuerdo que solo tú puedas interpretar. El color no determina tu personalidad, profesión ni cultura.
