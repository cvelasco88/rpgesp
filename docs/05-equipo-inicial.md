## Inventario base

Todo personaje comienza con una base de equipamiento funcional para explorar, sobrevivir y enfrentarse a amenazas.

### Inventario mínimo recomendado

- raciones para varios días
- antorcha o fuente de luz simple
- mochila o bolsa de transporte
- herramienta útil para la especialidad del personaje
- un objeto simbólico o personal

El inventario no tiene que ser enorme para empezar. Lo importante es que cada objeto tenga uso y provoque decisiones de estrategia.

## Equipo de partida

El equipo se puede dividir en varias categorías:

| Categoría | Ejemplos |
| --- | --- |
| Protección | Casco, chaleco, guantes, armadura ligera |
| Armas | Daga, arma a una mano, arma de distancia, arma improvisada |
| Herramientas | Pico, cuerda, lámpara, navaja, kit de exploración |
| Suministros | Raciones, agua, vendas, tintes, aceite |
| Objetos personales | Reliquias, símbolos, cartas, amuletos |

## Objetos habituales

| Objeto | Uso |
| --- | --- |
| Antorcha | Iluminación y amenaza a corta distancia |
| Cuerda | Escalada, trampas, manipulación |
| Raciones | Supervivencia y descanso |
| Vendas | Recuperación y estabilización |
| Kit de exploración | Revisión de terreno, pistas, rutas |
| Linterna | Iluminación segura |
| Bolsa | Almacenamiento y orden |

## Armamento y protección

| Clase | Ejemplos |
| --- | --- |
| Armas ligeras | Daga, garrote, cuchillo, martillo pequeño |
| Armas medias | Espada corta, hacha, maza, lanza |
| Armas de distancia | Honda, arco corto, ballesta ligera |
| Protecciones | Casco, peto ligero, guantes, armadura simple |

Cada arma o defensa debe indicar:

- daño base
- alcance o alcance posible
- si requiere una mano
- si tiene usos especiales

## Regla de carga

El inventario debe ser comprensible y rápido de usar. Si el personaje lleva demasiado equipo, puede verse obstaculizado por:

- reducción de movilidad
- pérdida de reacción o agilidad
- penalizaciones en la exploración
- necesidad de dejar objetos atrás

Se recomienda usar una regla clara:

- cada objeto ocupa un espacio
- objetos pequeños pueden agruparse
- objetos voluminosos ocupan dos o más espacios
- un personaje cargado no puede moverse ni actuar con normalidad

La carga debe ser una restricción narrativa útil, no una operación matemática pesada.
