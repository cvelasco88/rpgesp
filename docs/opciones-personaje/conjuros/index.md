## Cómo leer un conjuro

Cada conjuro define efecto, atributo, requisito, alcance, duración, coste y riesgo. Esos campos amplían [Magia](../../07-magia-y-poderes.md), que contiene las reglas comunes de lanzamiento y diseño.
