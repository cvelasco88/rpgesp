## Uso

Una subraza concreta una región, linaje, adaptación o tradición dentro de una raza. Las subrazas aportan una identidad más específica, pero no sustituyen los atributos, las competencias ni la historia del personaje.

## Cómo usar una subraza

Elige una subraza cuando quieras concretar el entorno, la tradición o el linaje del personaje. Sus rasgos deben describir una diferencia de ficción y no convertirse automáticamente en una bonificación numérica. Si una subraza necesita una capacidad mecánica, exprésala como competencia, dote o rasgo con requisitos claros.
