## Cómo usar este compendio

Estas opciones son herramientas para construir personajes, no requisitos para jugar. El Sistema Corporal sigue sin utilizar clases cerradas: una persona puede elegir una clase como orientación, mezclar rasgos de varias o crear un perfil propio con atributos, competencias, equipo y dotes.

Cada entrada debe responder a cuatro preguntas: qué fantasía propone, qué decisiones apoya, qué requisitos tiene y cómo se integra con la ficción. Si una opción contradice la historia del personaje, se puede cambiar por otra de la misma categoría con acuerdo de la mesa.

Los números y procedimientos comunes permanecen en [Creación del personaje](../01-creacion-personaje.md), [Atributos y especializaciones](../01-creacion-personaje-atributos.md) y [Magia](../07-magia-y-poderes.md). Las páginas de este compendio solo describen opciones y las enlazan; no repiten esas reglas.
