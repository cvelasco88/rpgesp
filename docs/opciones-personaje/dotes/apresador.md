## Sumario

## Requisitos

Competencia con un arma capaz de enganchar, atrapar o derribar y una ficción que justifique el intento.

## Efecto

Cuando impactas o superas una oposición física, puedes elegir sujetar, desequilibrar o arrastrar al objetivo en lugar de causar el efecto habitual. El guardián puede exigir una salvación o una tirada enfrentada si el objetivo es especialmente grande o fuerte.

La dote no elimina las consecuencias de una mala posición: describe dónde queda cada cuerpo y qué puede hacer el objetivo después.
