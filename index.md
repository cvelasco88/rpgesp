## Principios del sistema

El sistema se basa en cuatro pilares:

- neutralidad arbitral
- desarrollo progresivo
- especialización corporal
- ficción por delante de los números

### Neutralidad

El guardián actúa como árbitro imparcial, describe el mundo y resuelve situaciones de forma clara y consistente.

### Sin clases rígidas

El personaje no queda limitado a una clase cerrada. Su juego depende del desarrollo, el equipo, la experiencia y la especialización.

### Desarrollo por nivel

Cada personaje obtiene:

> 1 punto de desarrollo por nivel.

Se recomienda comenzar en nivel 1 con:

> 3 puntos de desarrollo iniciales.

| Nivel | Puntos totales |
| ----: | --------------: |
| 1 | 3 |
| 2 | 4 |
| 3 | 5 |
| 4 | 6 |
| 5 | 7 |
| 6 | 8 |
| 7 | 9 |
| 8 | 10 |
| 9 | 11 |
| 10 | 12 |
| 11 | 13 |
| 12 | 14 |

### La ficción va primero

Los dados ayudan a resolver la acción, pero no sustituyen la narración. El guardián puede decidir que la acción funciona, falla o cambia por criterios del escenario.

> Para ver la versión extensa de estos principios, consulta [Principios del sistema](./docs/00-principios.md).

## Creación del personaje

Un personaje se define por:

- nombre y concepto
- trasfondo
- atributos principales
- competencias o especializaciones
- puntos corporales
- equipo y estilo de juego

### Atributos principales

| Atributo | Descripción | Uso principal |
| --- | --- | --- |
| Cuerpo | Fuerza, resistencia, coordinación y vigor físico | Ataques físicos, atletismo, resistencia |
| Mente | Razonamiento, conocimiento y concentración | Investigación, magia, medicina, ingeniería |
| Espíritu | Voluntad, fe y conexión sobrenatural | Poderes, resistencia espiritual, rituales |
| Presencia | Autoridad, liderazgo y manipulación social | Persuasión, intimidación, mando |

### Puntos de desarrollo

Cada punto de desarrollo se asigna a un atributo:

- Cuerpo +1 = +2 puntos corporales
- Mente +1 = mejora del conocimiento y la lógica
- Espíritu +1 = mejora espiritual y sobrenatural
- Presencia +1 = +1 punto de competencia social

### Estadísticas derivadas

Las estadísticas principales no son cuatro copias de los atributos:

| Elemento | Cálculo o criterio |
| --- | --- |
| Vida | 8 + (Cuerpo × 2) + bonificación de Torso |
| Defensa | 10 + Cuerpo + características y equipo |
| Salvación | 1d20 + atributo apropiado + competencia |
| Ataque | 1d20 + atributo apropiado + competencia |

La bonificación de Torso se obtiene de esta escala:

| Puntos de Torso | Vida adicional |
| ---: | ---: |
| 0-1 | +0 |
| 2-3 | +2 |
| 4-5 | +4 |
| 6-7 | +6 |
| 8 o más | +8 |

> Consulta la sección completa en [Creación del personaje](./docs/01-creacion-personaje.md).

## Atributos y especializaciones

La diferencia entre un personaje fuerte y uno hábil no viene solo del valor bruto del atributo, sino también de las especializaciones y competencias:

| Competencia | Ejemplo |
| --- | --- |
| Cuerpo | Atletismo, Acrobacia, Resistencia |
| Mente | Investigación, Arcano, Medicina |
| Espíritu | Voluntad, Fe, Ocultismo |
| Presencia | Persuasión, Engaño, Liderazgo |

Se recomienda usar tablas de referencia para dejar claro qué hace cada personalidad, diversidad y nivel de especialización.

## Reglas base

Cuando una acción tiene una posibilidad real de fallar:

> 1d20 + atributo + competencia

El resultado se compara con:

- una dificultad del guardián
- la Defensa del objetivo
- la dificultad de un efecto

### Defensa

La Defensa representa lo difícil que es alcanzar a un personaje. Es un número fijo, principalmente físico.

> Defensa = 10 + Cuerpo + características + equipo

No se obtiene una bonificación automática por desarrollar piernas o pies. Esas zonas desbloquean habilidades de movimiento, equilibrio y evasión.

### Vida

La Vida combina la capacidad física general con el desarrollo del Torso:

> Vida = 8 + (Cuerpo × 2) + bonificación de Torso

### Salvaciones

Una salvación representa resistir un efecto peligroso. No existen cuatro defensas permanentes; se usa el atributo que mejor representa la amenaza:

> 1d20 + atributo apropiado + competencia

Ejemplos habituales:

| Efecto | Atributo habitual |
| --- | --- |
| Veneno o enfermedad | Cuerpo + Resistencia |
| Ilusión | Mente + Concentración |
| Maldición o posesión | Espíritu + Voluntad |
| Intimidación sobrenatural | Presencia + Voluntad |

> Consulta [Reglas base](./docs/03-reglas-base.md) para la versión completa.

## Sistema corporal

El sistema corporal es una de las piezas más importantes del diseño.

### Las 10 zonas del cuerpo

1. Cabeza
2. Torso
3. Brazo derecho
4. Brazo izquierdo
5. Puño derecho
6. Puño izquierdo
7. Pierna derecha
8. Pierna izquierda
9. Pie derecho
10. Pie izquierdo

### Función primaria de cada zona

| Zona | Función |
| ---- | ------ |
| Cabeza | Precisión, percepción, concentración |
| Torso | Resistencia, aguante, protección |
| Brazos | Cantidad, alcance, control |
| Puños | Potencia, daño, impacto |
| Piernas | Movilidad, salto, estabilidad |
| Pies | Equilibrio, precisión, esquiva |

### Regla de potenciación

Una habilidad puede usar como máximo:

> dos zonas corporales para potenciarse.

Esto mantiene el sistema rápido de resolver y evita habilidades con demasiados requisitos encadenados.

> La versión detallada está en [Sistema corporal](./docs/04-sistema-corporal.md).

## Resumen rápido

- Los atributos principales son Cuerpo, Mente, Espíritu y Presencia.
- El desarrollo es por nivel y por inversión de puntos.
- Cuerpo se especializa en 10 zonas corporales con funciones temáticas.
- La Vida depende de Cuerpo y del desarrollo del Torso.
- La Defensa es principalmente física y no recibe bonificaciones automáticas por piernas o pies.
- Las salvaciones usan el atributo y la competencia apropiados para cada efecto.
- Esquiva es una reacción que proporcionan determinadas habilidades, no una segunda Defensa.
- Las habilidades corporales siguen escalones para simplificar la resolución.
- Las reglas principales van por un manual de referencia, mientras que ejemplos y casos quedan en páginas auxiliares.
