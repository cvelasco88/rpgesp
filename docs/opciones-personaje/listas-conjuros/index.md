## Principio

Una lista de conjuros es una recomendación de acceso, no una frontera absoluta. La ficción, el arquetipo y el requisito del conjuro tienen prioridad. Un personaje puede aprender un conjuro de otra lista si existe una razón clara y un coste adecuado.
