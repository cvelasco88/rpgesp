## Principio

Una lista de capacidades sobrenaturales es una recomendación de acceso, no una frontera absoluta. La ficción, el arquetipo y los requisitos de la capacidad tienen prioridad. Un personaje puede aprender una capacidad de otra lista si existe una razón clara y un coste adecuado.

La organización debe hacerse por origen y manifestación, no por una única categoría de "magia" o por niveles que no existen en este sistema.

## Estructura recomendada

Las listas pueden clasificarse así:

- Trucos de Bendición
- Hechizos de Bendición
- Trucos de Maldición
- Hechizos de Maldición
- Trucos de Energía Planar
  - Elemental
  - Planar
  - Umbra
- Hechizos de Energía Planar
  - Elemental
  - Planar
  - Umbra

Las clases o razas pueden orientar el acceso, pero no deben convertirse en fronteras cerradas.

## Listas de referencia

| Lista | Enfoque | Acceso habitual |
| --- | --- | --- |
| Bendiciones | protección, vínculo, gracia, apoyo sobrenatural | Bendito, Profeta, figuras espirituales |
| Maldiciones | marcas, presión, consecuencias, dominio del entorno | personajes con la fuente impuesta, heredada o provocada |
| Energía Planar elemental | fuego, hielo, viento, sombra, niebla, electricidad | Hechicero, Planar, personajes con afinidad elemental |
| Energía Planar planar | espacio, distorsión, portales, gravedad, desplazamiento | Hechicero Planar, personajes con afinidad dimensional |
| Energía Planar de Umbra | ocultación, sombra, oscuridad, presencia inquietante | Umbríos o personajes con vínculo umbrío |

El catálogo de capacidades se completará cuando se cierre la revisión de las 100 entradas provisionales.
