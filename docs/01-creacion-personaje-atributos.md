## Principios del sistema

El sistema no utiliza clases cerradas. Todos los personajes comparten las mismas categorías, pero cada uno combina sus valores, competencias, armas, entrenamientos y dotes de forma distinta.

No mezcles estas categorías:

1. **Atributos:** Cuerpo, Mente, Espíritu y Presencia.
2. **Competencias generales:** capacidades con un valor de 0 a 5.
3. **Competencias de armas y armaduras:** permisos concretos; se poseen o no se poseen.
4. **Entrenamientos:** estilos o formas especiales de utilizar equipo.
5. **Dotes y rasgos:** capacidades que cambian una regla o desbloquean una acción.

Una prueba normal usa:

> 1d20 + atributo + competencia general

La competencia de arma no se suma a la tirada: permite utilizar correctamente ese tipo de arma. Los entrenamientos y las dotes tampoco tienen una puntuación.

## Atributos

| Atributo | Capacidad representada | Ejemplos de uso |
| --- | --- | --- |
| Cuerpo | Fuerza, coordinación, resistencia y velocidad corporal | Atletismo, acrobacia, fuerza bruta, resistencia física |
| Mente | Conocimiento, percepción intelectual y lógica | Investigación, arcano, medicina, tecnología |
| Espíritu | Voluntad, fe, conexión espiritual y resistencia sobrenatural | Poderes, resistencia a maldiciones, fe |
| Presencia | Autoridad, carisma, liderazgo y manipulación social | Persuasión, intimidación, liderazgo, engaño |

Una misma competencia puede utilizar distintos atributos cuando cambia el enfoque. Por ejemplo, **Sigilo** suele usar Cuerpo, pero una maniobra social para ocultar intenciones puede usar Presencia.

## Competencias generales

Las competencias generales tienen un valor de 0 a 5:

| Valor | Nivel |
| ---: | --- |
| 0 | Sin entrenamiento |
| 1 | Básico |
| 2 | Competente |
| 3 | Experto |
| 4 | Maestro |
| 5 | Excepcional |

### Cuerpo

| Competencia | Uso |
| --- | --- |
| Atletismo | Levantar, empujar, trepar, nadar, saltar, correr y mantener una posición física |
| Acrobacia | Equilibrio, maniobras, aterrizajes y evitar caídas |
| Combate | Entrenamiento general en combate cuerpo a cuerpo y técnicas marciales |
| Sigilo | Ocultarse, infiltrarse y moverse sin ser detectado |
| Juego de manos | Robar, ocultar objetos, abrir mecanismos sencillos y hacer trucos manuales |

### Mente

| Competencia | Uso |
| --- | --- |
| Percepción | Detectar objetos, sonidos, movimientos, peligros y detalles |
| Investigación | Analizar escenas, encontrar pistas y relacionar información |
| Historia | Recordar acontecimientos, reinos, guerras, familias y culturas |
| Arcano | Conocer magia, criaturas mágicas, objetos, rituales y fenómenos arcanos |
| Naturaleza | Conocer animales, plantas, clima y terreno |
| Medicina | Diagnosticar, tratar heridas, enfermedades y venenos |
| Tecnología | Comprender mecanismos, máquinas, herramientas e ingeniería |

### Espíritu

| Competencia | Uso |
| --- | --- |
| Voluntad | Resistir miedo, control mental, posesión, corrupción y dominación |
| Fe | Conocer y practicar religiones, divinidades y ritos sagrados |
| Ocultismo | Conocer espíritus, maldiciones, entidades y rituales prohibidos |
| Supervivencia | Rastrear, orientarse, encontrar alimento y refugio |
| Instinto | Percibir peligros o anomalías sin comprender necesariamente su causa |

### Presencia

| Competencia | Uso |
| --- | --- |
| Persuasión | Convencer, negociar y mediar |
| Engaño | Mentir, manipular y ocultar intenciones |
| Intimidación | Amenazar, presionar e imponer autoridad |
| Liderazgo | Dar órdenes, organizar, inspirar y mantener la moral |
| Actuación | Interpretar, cantar, bailar, entretener y representar personajes |

## Competencias de armas

Las competencias de armas no tienen valores de 0 a 5. El personaje las posee o no las posee. Permiten utilizar correctamente el arma y acceder a sus técnicas básicas, pero no se suman a las tiradas.

### Cuerpo a cuerpo

**Ligeras:** daga, hacha de mano, martillo ligero, hoz, cimitarra y espada corta.

**De una mano:** garrote, maza, mayal, estrella de la mañana, estoque o florete y pico de guerra.

**Versátiles:** jabalina, lanza, bastón, hacha de batalla, espada larga, tridente y martillo de guerra.

**De dos manos:** gran garrote, pica, guja, alabarda, gran hacha, mandoble y gran martillo o maza de guerra.

### A distancia

**Arcos:** arco corto y arco largo.

**Ballestas:** ballesta de mano, ballesta ligera y ballesta pesada.

Las categorías “cuerpo a cuerpo”, “a distancia”, “ligera” y “versátil” organizan las armas, pero no sustituyen una competencia concreta.

## Armaduras

Las armaduras utilizan permisos independientes de las armas:

- armadura ligera
- armadura media
- armadura pesada
- escudos

Una competencia de armadura permite utilizarla correctamente. Una pieza concreta puede exigir además un atributo o una dote, por ejemplo: **armadura pesada: Cuerpo 4 y competencia con armadura pesada**.

## Entrenamientos

Los entrenamientos no tienen puntuación. El personaje los posee o no los posee, y no sustituyen la competencia con el arma concreta.

| Entrenamiento | Efecto |
| --- | --- |
| Combate a dos manos | Permite técnicas especiales con armas que requieren ambas manos |
| Combate con dos armas | Permite técnicas con un arma en cada mano cuando sean compatibles |
| Combate con escudo | Permite usar el escudo ofensivamente y acceder a técnicas defensivas |
| Combate montado | Permite técnicas especiales desde una montura |
| Armas arrojadizas | Permite usar ciertas armas cuerpo a cuerpo como armas a distancia |

Para una técnica avanzada con un mandoble hacen falta, como mínimo, competencia con Mandoble y entrenamiento de Combate a dos manos, además de los requisitos corporales de la técnica.

## Dotes y rasgos

Una dote debe cambiar una regla, desbloquear una acción, proporcionar una reacción, modificar una capacidad o permitir algo que un personaje normal no puede hacer. No uses una dote para representar una competencia numérica: `+2 a Historia` pertenece a la competencia Historia.

Cada dote debe indicar:

- tipo: combate, defensa, exploración, social, mágica, espiritual, corporal o especial
- requisitos: atributos, competencias, armas, entrenamientos, zonas corporales o dotes previas
- efecto
- acción: acción, reacción, pasiva o acción adicional
- escalado, si utiliza zonas corporales

### Ejemplos

**Pies ligeros.** Requiere Pie derecho 2 y Pie izquierdo 2. Obtienes la reacción Esquiva.

**Defensa férrea.** Requiere Torso 2, Brazo derecho 2 y Brazo izquierdo 2. Obtienes +2 a Defensa.

**Combate a dos manos.** Requiere la competencia del arma y los requisitos corporales definidos por la técnica. Desbloquea técnicas especiales a dos manos.

**Combate con dos armas.** Requiere las competencias de las armas utilizadas. Permite técnicas especiales con dos armas compatibles.

**Maestro del arco.** Requiere competencia con arco y Combate 3. Desbloquea técnicas avanzadas de arco.

**Maestro de la ballesta.** Requiere competencia con una ballesta y Combate 3. Desbloquea técnicas avanzadas de ballesta.

**Especialista en espada.** Requiere competencia con espada. Desbloquea técnicas especiales de espada.

## Requisitos corporales

Los puntos corporales sirven para desbloquear dotes y potenciar habilidades, pero no se suman directamente a las tiradas normales.

Si una dote requiere Torso 2, Brazo derecho 2 y Brazo izquierdo 2, el personaje cumple o no cumple el requisito; no suma esos valores para crear un bono.

Una dote o habilidad puede utilizar como máximo dos zonas corporales para escalar directamente su efecto. Las demás zonas pueden aparecer como requisitos, pero no participan en el cálculo.

Ejemplo: **Tajo devastador** requiere competencia con Mandoble, Combate a dos manos, Brazo derecho 3, Brazo izquierdo 3 y Puño derecho 2. El ataque sigue usando la tirada normal; los puntos corporales solo desbloquean la técnica.

Para la distribución y el escalado de las zonas, consulta [Sistema corporal](./03-reglas-sistema-corporal.md).

## Estructura de la ficha

La ficha debe separar estos bloques:

- **Atributos:** Cuerpo, Mente, Espíritu y Presencia.
- **Competencias generales:** las competencias de cada atributo, con valores de 0 a 5.
- **Competencias de armas:** armas concretas que el personaje sabe utilizar.
- **Armaduras:** ligera, media, pesada y escudos.
- **Entrenamientos:** estilos de combate y técnicas de uso del equipo.
- **Dotes y rasgos:** capacidades especiales.
- **Desarrollo corporal:** Cabeza, Torso, brazos, puños, piernas y pies, con sus lados cuando corresponda.

## Desarrollo y mejora

### Nivel de desarrollo por atributo

| Valor | Significado | Uso típico |
| --- | --- | --- |
| 1 | Inicial / básico | Personaje novato |
| 2 | Competente | Especialización pequeña |
| 3 | Habitual | Persona muy capaz |
| 4 | Destacada | Especialista reconocido |
| 5 | Excelente | Máxima competencia general |

### Ejemplo de progresión sugerida

| Atributo | Desarrollo inicial | Desarrollo medio | Desarrollo avanzado |
| --- | --- | --- | --- |
| Cuerpo | 1 | 2-3 | 4-5 |
| Mente | 1 | 2-3 | 4-5 |
| Espíritu | 1 | 2-3 | 4-5 |
| Presencia | 1 | 2-3 | 4-5 |

> El sistema no exige una escala rígida igual para todos los personajes. La tabla sirve como referencia para una mesa ordenada y equilibrada.

### Conversión de puntos de atributo

Esta tabla resume qué compra cada punto de atributo. Los efectos concretos de una habilidad pueden exigir además una característica o una zona corporal.

| Atributo | Cada punto aporta | Conversión práctica |
| --- | --- | --- |
| Cuerpo | 2 puntos corporales | Reparte los puntos entre las diez zonas del cuerpo |
| Mente | 1 mejora de Mente | Aumenta una competencia general vinculada a Mente o desbloquea una dote mental |
| Espíritu | 1 mejora de Espíritu | Aumenta una competencia general vinculada a Espíritu o desbloquea una dote espiritual |
| Presencia | 1 mejora de Presencia | Aumenta una competencia general vinculada a Presencia o desbloquea una dote social |

| Valor del atributo | Lectura de referencia |
| ---: | --- |
| 1 | Capacidad básica o formación inicial |
| 2 | Persona competente |
| 3 | Especialista fiable |
| 4 | Referente en su campo |
| 5 | Límite excepcional de una persona normal |

Los valores superiores a 5 deben justificarse mediante poderes, transformaciones, reliquias o circunstancias extraordinarias.

### Características defensivas

Las características defensivas dan herramientas concretas sin convertir cada atributo en una Defensa distinta.

| Característica | Requisito | Efecto |
| --- | --- | --- |
| Mente protegida | Mente 4 | +2 a salvaciones contra ilusiones y manipulación mental |
| Voluntad férrea | Espíritu 3 | +2 a salvaciones contra miedo, posesión y corrupción |
| Canalización | Espíritu 2 | Permite utilizar determinados poderes; no es una competencia numérica |
| Pies ligeros | Pie derecho 2 y Pie izquierdo 2 | Obtienes la reacción Esquiva |

**Esquiva** permite evitar un ataque concreto cuando la ficción lo permite. No aumenta automáticamente la Defensa.

Una mejora de competencia general aumenta en 1 el valor de una competencia elegida, hasta un máximo de 5. Las competencias de armas, armaduras y los entrenamientos se desbloquean mediante elección, trasfondo, práctica o dotes; no se compran como valores de 0 a 5.

## Regla práctica

Para mantener el sistema equilibrado, conviene fijar un marco de referencia al comenzar la campaña:

- todos los personajes deberían poder competir con el conjunto de la partida
- los personajes muy especializados deben tener un coste en otras áreas
- cada habilidad debe explicitar qué la activa y qué la potencia

Para más detalle sobre reglas de tirada, consulta [Reglas](./03-reglas.md).
