## Regla de diseño

Una dote cambia una regla, desbloquea una acción o proporciona una reacción. No es una bonificación genérica y no sustituye una competencia. Cada dote debe indicar requisitos, efecto y momento de uso, según [Atributos y especializaciones](../../01-creacion-personaje-atributos.md).
